# Instituto Bruner · Catálogo de cursos

Landing page responsive para presentar los cursos de oficios de Instituto Bruner.

## Contenido

- Catálogo filtrable por área.
- Fichas con modalidad, duración, dedicación y contenidos.
- Diseño responsive y accesible.
- Enlaces al sitio oficial para consultas e inscripciones.

Los datos de los cursos se basan en la oferta publicada en [brunerinstituto.com](https://brunerinstituto.com/).
